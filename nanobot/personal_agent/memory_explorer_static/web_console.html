Conversation records are stored in Supabase PostgreSQL. The connection is made only by this Mac controller. Use the restricted toothless_runtime login after the reviewed migrations are applied. Do not use a service-role key or administrator credential.

The DSN is stored in ~/.config/toothless/web-console.env with owner-only permissions; it is not sent to the browser or Ubuntu worker.

Database setup and current limits

Apply ops/supabase/migrations/0001_toothless_web.sql then 0002_toothless_web_auth.sql in the intended Supabase project. Create a dedicated non-superuser login with no RLS bypass and membership in toothless_web. The controller verifies the schema before storing the DSN.

Conversation persistence is separate from execution. Automatic dispatch, approvals, event streaming, and resume remain disabled; nothing starts from this page.
