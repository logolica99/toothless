## Implementation

The new optional Memory Explorer is `nanobot.personal_agent.memory_explorer`, an aiohttp app bound to `127.0.0.1` only. It opens the existing MemoryStore and TaskStore with SQLite read-only/query-only connections and never migrates, writes, starts a VM, or dispatches work. API requests require a random bearer token; the middleware also checks loopback peer, Host, and Origin. Responses use no-store, nosniff, no-referrer, and a restrictive same-origin CSP. The interface uses vendored Cytoscape.js 3.35.0 with its license and version file, with no third-party runtime fetch. Search and expansion are bounded; project/type filters, zoom/pan/drag, node selection, relationship inspection, provenance, current/superseded memory history, and incremental graph updates are available.

Telegram responses now use reusable HTML cards and inline controls for pending task approval/rejection, task details/cancellation, research source pagination/details/save-to-memory, and schedule approval/pause/resume/cancel. Text commands remain available. Callback IDs are random, one-use references stored with owner, private chat, message, action, and expiry bindings. The handler acknowledges callbacks and rechecks authoritative TaskStore, MemoryStore, or ScheduleStore state before a state change. Approval buttons consume the existing exact-action proposal and approval snapshot; they do not bypass `/run` semantics. Stale and duplicate controls do not repeat state transitions.

Completed research cards use a bounded list of validated public HTTP(S) titles and URLs in `task_sources`; raw webpage contents are not stored. Credential-bearing URLs, private/local destinations, unusual ports, credential-like query keys, and overlong URLs are excluded. Source controls only display links. Host result-delivery status is derived from persisted TaskStore delivery rows, not model text.

Exact source content and individual button replies were not provided, so the report does not reproduce those values. A direct second-account request was not performed; deterministic tests cover unauthorized owner/chat/API access. The screenshot used for local browser visual inspection was not retained as a repository artifact because it showed private project/task records. The callback persistence test recreates the store against the same SQLite file; a pre-restart Telegram button was not explicitly reported as pressed after restart.

The reminder-intent parser correction is covered by a local regression test and live schedule creation, while the earlier intentionally approved workspace task remains failed and must not be retried. The dashboard and source callbacks never dispatch worker work, and no broader scheduling or execution scope was enabled.
