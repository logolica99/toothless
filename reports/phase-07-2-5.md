## Changes made

- The trusted visible-browser broker now obtains the Playwright driver process from the Playwright connection transport, and reports driver and Chromium identities separately. Chromium is attributed only when its process is found in the driver-descendant chain, not from process name alone. The broker collects bounded process/thread counts for the service cgroup and nested scopes, role summaries for desktop/browser processes, service and up to three parent-cgroup PID counters, and existing PID/memory/CPU/FD measurements and event deltas. Unavailable process or cgroup metrics remain unknown. No command lines, environments, credentials, webpage text, profile paths, or browser payloads are collected.
- Browser research instructions now prioritize the exact requested evidence, extract relevant navigation links in one pass, avoid revisiting checked URLs, avoid speculative paths, and report incomplete coverage. They do not silently redefine an explicit request for every tag as a request for header categories. The existing 12-step limit is unchanged; there is no evidence here to justify increasing it.
- Browser source provenance now travels through a task-private, bounded helper manifest containing only title, observed URL, optional label, HTTP status, and evidence state. The helper distinguishes a page actually visited (`observed`) from a same-host navigation link found in rendered page structure but not visited (`linked_unvisited`). The guest runner validates owner, mode, path, size, schema, and URL before returning the manifest. The host validates it again and persists it in TaskStore. Page contents, raw history, and model reasoning are not included.
- URLs parsed from model answer text are no longer promoted to browser-verified TaskStore records. Historical/legacy answer-derived records retain the `reported` status and are presented as unverified rather than as evidence of browser navigation. Host source recording is append-positioned, avoiding collision with such legacy rows.
- Existing fatal browser-session invalidation, bounded partial results, `incomplete` outcomes, no-retry behavior, and terminal-task idempotence were left intact.
